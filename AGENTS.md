# e-hishabsathi-mobile

The repo root is `e-hishabsathi-mobile/` (git, package.json, expo config all live here) — the outer directory is just a container. Run all commands from inside the project.

## Before writing code

- **Expo HAS CHANGED**: this is SDK 57. Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.
- Read `doc/guide0.0.1-alpha.1.md` before changing architecture or data flow; read `src/shared/constants/README.md` before touching colors, spacing, radius, or typography.

## Architecture rules (enforced, see guide)

- Data flow is `Screen → feature hook → feature data layer → SQLite`. Screens never run SQL directly.
- Route files in `src/app/` must be thin re-exports only: `export { default } from "@/features/sales/SalesScreen";`. Known violations to fix: `src/app/(tabs)/05-settings.tsx`, `src/app/(auth)/business-type.tsx`, `src/app/(auth)/onboarding.tsx` still render inline UI.
- Features in `src/features/<name>/` own their components, hooks, `data/`, `utils/`, `validation.ts` (Zod), and `types.ts`. Reusable-only UI goes in `src/shared/components/`.
- Business data lives in SQLite, never duplicated in Zustand stores (stores hold UI state only).
- Styling uses page token sets (e.g. `Colors_SalesPage`, `Typography_DashboardPage`) — there is no single global theme.

## Gotchas

- `track.ts` / `t.ts` files are empty git-placeholder files — **never edit or write to them**. Many feature folders are stubs containing only these.
- SQLite is not implemented yet: hooks like `useSalesEntries` return `*.mock.ts` data, and `src/database/{schema,migrations,seeds}/` contain only placeholders.
- Path aliases (tsconfig, strict): `@/*` → `src/*`, `@/assets/*` → `assets/*`.
- `metro.config.js` registers `.wasm` as an asset (for wa-sqlite) — don't revert that.
- React Compiler and typed routes are enabled in `app.json` experiments; `.expo/types` is generated by `expo start`.

## Commands

- Dev: `npm start`, `npm run android`, `npm run ios`, `npm run web`
- Lint: `npm run lint` (expo lint). There is no test or typecheck script — verify types with `npx tsc --noEmit`.
